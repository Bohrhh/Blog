# Color Shifting in CSS

A little while ago, I was trying to animate an element's background color, so that it cycled through the rainbow.

## The Problem

Browsers have a surprisingly big limitation when it comes to color processing!

## Solutions

Here are a couple of strategies you can use to work around this limitation:

- Use CSS custom properties
- Break down colors into HSL components
- Use @property to animate custom properties
