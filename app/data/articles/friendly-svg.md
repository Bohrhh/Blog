# A Friendly Introduction to SVG

SVGs are one of the most remarkable technologies we have access to on the web.

## What is SVG?

SVG stands for Scalable Vector Graphics. They're first-class citizens, fully addressable with CSS and JavaScript.

## Getting Started

```html
<svg viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" />
</svg>
```

## Styling with CSS

You can style SVG elements just like regular HTML elements!

## Conclusion

Go explore the wonderful world of SVG!
