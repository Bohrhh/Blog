# Next-level frosted glass with backdrop-filter

Glassy headers have become a core part of the "slick startup" UI toolkit.

## The Basics

```css
.glass {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(10px);
}
```

## Pro Tips

Add a subtle border for extra depth!

```css
.glass {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.2);
}
```

Create beautiful glass effects!
